About this class

This site collects everything for the class in one place. Use it to check what is due, find readings, and reach the instructor. New material will be added here as the term goes on.

By the end of the class you will be able to:

  • Set clear career goals and a plan to reach them
  • Write a strong resume and professional profile
  • Communicate confidently in interviews and meetings
  • Build and maintain a professional network
